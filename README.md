# 위험물기능장 실기 학습 도구

제57~78회 실기 기출 426문항을 안키식 반복학습으로 복습하는 개인 학습 도구입니다.

## 사용 방법

1. `index.html`과 `question_bank.js`를 같은 폴더에 둡니다.
2. `index.html`을 브라우저에서 엽니다.
3. 문제를 먼저 풀고 **원문 정답·해설 보기**를 눌러 정답, 원문 해설, 문항별 암기법·풀이 포인트를 확인합니다.
4. `다시`, `어려움`, `외움`으로 복습 간격을 조절합니다.

## 포함 자료

- `index.html` — 카드 복습 화면과 문항별 쪽집게 암기·풀이 안내
- `question_bank.js` — 회차별 문제, 원문 정답·해설과 분류 정보
- `426문항_분석요약.md` — 반복 유형 및 출제 분포 분석
- `최우선_암기노트.md` — 우선순위별 핵심 암기 정리

학습도구는 반응식·계산·법규·시설·소화·운반·물질 판별 등 문항 유형에 따라 풀이 순서와 기억고리를 제공합니다. 기출 426문항의 원문 답안과 해설은 카드 뒤집기에서 바로 확인할 수 있습니다.

법령 수치와 기준은 시험 연도에 맞는 최신 자료로 확인하세요.
